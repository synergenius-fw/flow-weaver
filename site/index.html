Workflows that compile to TypeScript you own.

Flow Weaver is a deterministic TypeScript workflow compiler. You describe a workflow with JSDoc annotations, and it compiles to a standalone TypeScript function that imports nothing from Flow Weaver. A run can pause for a person, an AI agent or a timer, and resume where it stopped.

Get started

Make your own in a minute.

You need Node.js 22 or later.

  1. 1
    Create a project with a first workflow.
    npx @synergenius/flow-weaver init my-project
  2. 2
    Run it.
    cd my-project && npm start
  3. 3
    Open the console to see your workflows, their runs and their gates.
    npx fw console
  4. 4
    Or let your AI assistant build workflows with you, through Flow Weaver's MCP tools.
    npx fw mcp-setup
